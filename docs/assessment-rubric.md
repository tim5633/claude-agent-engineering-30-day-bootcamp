# Mastery Rubric

依自我評分 0–4：0 未理解；1 能描述；2 參考文件完成；3 獨立完成與測試；4 能設計取捨、審查他人並向客戶說明。

| 能力 | 目標 |
|---|---:|
| Claude Code advanced workflow | 4 |
| Claude API tool calling | 4 |
| Agent SDK | 3 |
| MCP implementation | 3 |
| Security & authorization | 3 |
| Evaluations & regression | 3 |
| Deployment & observability | 3 |
| Architecture & client communication | 3 |

每個 3 或 4 分必須有 commit、測試、architecture note 或 demo 支持。**此評量不是官方認證標準。**

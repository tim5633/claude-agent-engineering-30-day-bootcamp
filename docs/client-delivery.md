# Client Delivery Pack

## Discovery questions

1. 使用者是誰？任務與現在的人工流程是什麼？
2. 哪個 KPI 能證明成果（時間、品質、風險或成本）？
3. 有哪些資料來源、存取權和 retention requirements？
4. 哪些操作需要人工審核？
5. SLA、吞吐量、併發、回復時間要求？
6. 目前的風險、維運、資安與審計責任歸誰？

## Required documents

- [ ] Business requirements and success criteria
- [ ] As-is / to-be architecture
- [ ] Options and ADRs
- [ ] Threat model and risk register
- [ ] Evaluation plan and acceptance gates
- [ ] TCO / cost-per-task model
- [ ] RACI, milestones, support and incident runbook
- [ ] 20-minute technical presentation + 15-minute demo + 20-minute Q&A

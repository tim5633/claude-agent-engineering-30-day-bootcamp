# Mastery rubric

Score 0–4 per area: 0 no evidence, 1 guided, 2 working demo, 3 independently repeatable, 4 reliable and defensible.

Claude Code; Claude API; Agent SDK; MCP; Security; >=50 Eval cases; Tracing/Cost; Deployment; Architecture; Client Communication.

Suggested graduation: all areas >=3 and final go-live simulation passed. This is not an official Anthropic exam standard.

# 能力驗收標準

每個領域給予 0–4 分：0 無證據、1 需引導、2 可執行展示、3 可獨立重現、4 可靠安全且能辯護。

評估 Claude Code、API、Agent SDK、MCP、安全、至少 50 個評估案例、追蹤與成本、部署、架構、英文客戶簡報。

建議畢業門檻是各領域至少 3 分並完成上線故障演練；這不是 Anthropic 官方認證門檻。
